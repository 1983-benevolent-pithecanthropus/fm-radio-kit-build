# FM Radio Kit — Assembly and Testing

## Overview
I assembled a low-cost radio receiver kit purchased from Temu for approximately £2.

I did not design the PCB or receiver circuit, and no programming was required.  
I only soldered the components on the PCB and tested it. 

## Objectives
- Practise through-hole soldering.
- Identify and correctly install the supplied components.
- Test the completed radio.
- Document the assembly process and lessons learned.
